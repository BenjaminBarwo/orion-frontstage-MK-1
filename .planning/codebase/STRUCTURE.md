## Directory Purposes

**app/ (Routes and Pages):**
- Purpose: Application navigation structure and page components
- Contains: Route files (*.tsx), layout definitions (_layout.tsx), modal definitions
- Key files: `_layout.tsx` (root), `(tabs)/_layout.tsx` (tab config), `(tabs)/index.tsx` (home), `(tabs)/explore.tsx` (explore page), `modal.tsx` (modal)

**components/ (Reusable UI):**
- Purpose: Composable, reusable React components used across pages
- Contains: Themed wrapper components, UI primitives, layout components, utility components
- Key files: `themed-text.tsx`, `themed-view.tsx`, `parallax-scroll-view.tsx`, `ui/collapsible.tsx`

**components/ui/ (Base UI Library):**
- Purpose: Low-level, single-responsibility UI components
- Contains: Icon symbol wrapper, collapsible component
- Key files: `icon-symbol.tsx` (icon abstraction), `collapsible.tsx` (expandable container)

**hooks/ (Stateful Logic):**
- Purpose: Encapsulate component logic and cross-cutting concerns
- Contains: React hooks for theme management, color scheme detection
- Key files: `use-color-scheme.ts`, `use-theme-color.ts`

**constants/ (Configuration):**
- Purpose: Application-wide static values and configuration
- Contains: Color definitions, font specifications, theme configuration
- Key files: `theme.ts` (Colors and Fonts objects)

**assets/ (Static Resources):**
- Purpose: Images, icons, and other static media files
- Contains: PNG images organized by type
- Key files: `images/icon.png`, `images/splash-icon.png`, `images/android-icon-*.png`

**scripts/ (Automation):**
- Purpose: Build and development automation scripts
- Contains: Node.js scripts for project setup and reset
- Key files: `reset-project.js`

**.planning/codebase/ (Architecture Documentation):**
- Purpose: GSD framework analysis and planning documents
- Contains: Architecture, structure, conventions, testing, concerns analysis
- Generated by: `/gsd:map-codebase` commands

## Key File Locations

**Entry Points:**
- `app/_layout.tsx`: Root layout, theme provider, navigation stack setup - main application entry point
- `package.json`: "main" field points to "expo-router/entry" which loads app/_layout.tsx
- `app/(tabs)/_layout.tsx`: Tab navigator configuration - defines bottom tab navigation structure

**Configuration:**
- `app.json`: Expo application metadata, plugins, experiments (newArchEnabled, reactCompiler, typedRoutes)
- `tsconfig.json`: TypeScript compiler options with "@/*" path alias pointing to root
- `eslint.config.js`: ESLint configuration extending expo config
- `package.json`: Dependencies, dev dependencies, and npm scripts

**Core Logic:**
- `constants/theme.ts`: Color definitions for light/dark themes, platform-specific fonts
- `hooks/use-theme-color.ts`: Theme color resolution logic - core theming mechanism
- `components/parallax-scroll-view.tsx`: Complex animation logic using react-native-reanimated

**UI Components:**
- `components/themed-text.tsx`: Text component with theme awareness
- `components/themed-view.tsx`: View component with theme awareness
- `components/ui/collapsible.tsx`: Expandable content container
- `components/ui/icon-symbol.tsx`: Icon abstraction layer

## Naming Conventions

**Files:**
- Kebab-case for multi-word filenames: `parallax-scroll-view.tsx`, `external-link.tsx`
- PascalCase exports for React components, kebab-case filenames: `export function ThemedText` in `themed-text.tsx`
- Underscore prefix for special routing files: `_layout.tsx`, `_layout.web.ts`
- Platform-specific suffixes: `.ios.tsx`, `.web.ts` (e.g., `icon-symbol.ios.tsx`)
- Index files for barrel exports: `components/index.tsx` (if used)

**Directories:**
- Kebab-case for feature directories: `components/ui/`, `assets/images/`
- Parentheses for route grouping: `app/(tabs)/` - creates grouped navigation without affecting URL structure
- Lowercase descriptive names: `hooks/`, `constants/`, `assets/`, `scripts/`

**Functions/Components:**
- PascalCase for React components: `function ThemedText()`, `export function HapticTab()`
- camelCase for utility functions and hooks: `useColorScheme()`, `useThemeColor()`
- Descriptive names matching responsibility: `ParallaxScrollView`, `ExternalLink`, `HelloWave`

**Types:**
- PascalCase with Type/Props suffix: `ThemedTextProps`, `BottomTabBarButtonProps`
- Generic type variable names: `Props`, `T`, `PropsWithChildren`

## Where to Add New Code

**New Feature:**
- Primary code: Add route file to `app/` directory (e.g., `app/newfeature.tsx` or `app/(groupname)/newfeature.tsx`)
- Tests: Create alongside feature in `__tests__/` or `.test.tsx` file (no test framework configured yet)
- Shared UI: Extract to `components/` directory
- Logic: Extract to `hooks/` if stateful, `constants/` if static configuration

**New Component/Module:**
- Presentational component: `components/my-component.tsx`
- Base UI primitive: `components/ui/my-ui-element.tsx`
- Layout component: `components/my-layout.tsx`
- Follow naming: kebab-case filename, PascalCase export

**Utilities:**
- Custom hooks: `hooks/use-my-feature.ts`
- Constants: `constants/my-config.ts`
- Platform-specific logic: Add `.ios.ts`, `.web.ts` suffixes as needed

**Styling:**
- Inline styles: Use `StyleSheet.create()` at bottom of component file (see `app/(tabs)/index.tsx`)
- Theme colors: Reference `Colors` from `constants/theme.ts` via `useThemeColor()` hook
- Fonts: Reference `Fonts` from `constants/theme.ts` and apply via `fontFamily` style prop

**Navigation:**
- Tab routes: Add to `app/(tabs)/_layout.tsx` with Tabs.Screen configuration
- Stack routes: Add to `app/_layout.tsx` with Stack.Screen configuration
- Modals: Add to `app/` root with modal presentation option in Stack.Screen
- Grouped routes: Create new directory with parentheses like `app/(groupname)/`

## Special Directories

**app/(tabs)/ (Grouped Route Directory):**
- Purpose: Visually group related routes without affecting URL structure
- Generated: No
- Committed: Yes
- Contains: Home and Explore tab screens, shared tab layout
- Pattern: Routes in this directory appear as tabs in the bottom tab bar

**assets/images/ (Static Images):**
- Purpose: Store image assets for different screen densities
- Generated: No (populated manually)
- Committed: Yes
- Images: Support @2x and @3x suffixes for density variants

**node_modules/ (Dependencies):**
- Purpose: Installed package dependencies
- Generated: Yes (by npm install)
- Committed: No (excluded from git)
- Populated by: package.json and package-lock.json

**.expo/ (Build Artifacts):**
- Purpose: Expo development server and build cache
- Generated: Yes (by expo start)
- Committed: No
