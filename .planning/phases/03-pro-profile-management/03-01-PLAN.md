Create `supabase/migrations/00001_create_profiles.sql` with:

```sql
-- Profiles table
-- Auto-created via Postgres trigger on auth.users insert
CREATE TABLE IF NOT EXISTS public.profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  first_name TEXT,
  last_name TEXT,
  display_name TEXT, -- computed: "first_name last_name"
  role_category TEXT CHECK (role_category IN ('lender', 'real_estate_agent', 'attorney', 'title_escrow', 'home_inspector')),
  zip_code TEXT,
  bio TEXT CHECK (char_length(bio) <= 300),
  avatar_url TEXT,
  onboarding_completed BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;

-- RLS Policies
-- Users can read any profile (needed for feed/discovery)
CREATE POLICY "Profiles are viewable by authenticated users"
  ON public.profiles FOR SELECT
  TO authenticated
  USING (true);

-- Users can only update their own profile
CREATE POLICY "Users can update own profile"
  ON public.profiles FOR UPDATE
  TO authenticated
  USING (auth.uid() = id)
  WITH CHECK (auth.uid() = id);

-- Users can insert their own profile (for trigger)
CREATE POLICY "Users can insert own profile"
  ON public.profiles FOR INSERT
  TO authenticated
  WITH CHECK (auth.uid() = id);

-- Auto-create profile on user signup
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO public.profiles (id, created_at)
  VALUES (NEW.id, NOW());
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

-- Trigger on auth.users insert
DROP TRIGGER IF EXISTS on_auth_user_created ON auth.users;
CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();

-- Auto-update updated_at timestamp
CREATE OR REPLACE FUNCTION public.handle_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER on_profile_updated
  BEFORE UPDATE ON public.profiles
  FOR EACH ROW EXECUTE FUNCTION public.handle_updated_at();
```

**Step 2: Create profile service**

Create `lib/profile-service.ts` — Supabase profile CRUD and photo upload operations.

Define `Profile` interface matching database columns:
- `id: string`, `first_name: string | null`, `last_name: string | null`, `display_name: string | null`, `role_category: RoleCategory | null`, `zip_code: string | null`, `bio: string | null`, `avatar_url: string | null`, `onboarding_completed: boolean`, `created_at: string`, `updated_at: string`

Functions:

1. `getProfile(userId: string): Promise<Profile | null>` — Fetch profile from Supabase. Return null if not found. Select single row by id.

2. `uploadProfilePhoto(uri: string, userId: string): Promise<string>` — Convert local URI to ArrayBuffer via `fetch(uri).then(r => r.arrayBuffer())`. Generate file path `{userId}/{userId}-{Date.now()}.jpeg`. Upload to `avatars` bucket with `contentType: 'image/jpeg'` and `upsert: true`. Return public URL from `supabase.storage.from('avatars').getPublicUrl()`.

3. `saveProfile(userId: string, data: { firstName: string; lastName: string; role: RoleCategory; zipCode: string; bio: string; photoUri: string }): Promise<void>` — Orchestrate full profile save:
   - Call `uploadProfilePhoto(data.photoUri, userId)` to upload photo and get URL
   - Call `supabase.from('profiles').update({...}).eq('id', userId)` with:
     - `first_name: data.firstName`
     - `last_name: data.lastName`
     - `display_name: \`${data.firstName} ${data.lastName}\``
     - `role_category: data.role`
     - `zip_code: data.zipCode`
     - `bio: data.bio`
     - `avatar_url: avatarUrl` (from upload)
     - `onboarding_completed: true`
   - Throw on any error with descriptive message

4. `updateProfile(userId: string, updates: Partial<Omit<Profile, 'id' | 'created_at' | 'updated_at'>>): Promise<void>` — Update specific profile fields. Used for post-onboarding edits.

Import supabase from `@/lib/supabase`. Import `RoleCategory` from `@/constants/roles`.

**Step 4: Create profile photo picker functions**

Create `components/profile/profile-photo-picker.tsx`:

Export two async functions:

1. `pickProfilePhoto(): Promise<string | null>` — Request media library permissions. Launch `ImagePicker.launchImageLibraryAsync` with `allowsEditing: true`, `aspect: [1, 1]`, `quality: 1`. If cancelled, return null. Otherwise, resize with `ImageManipulator.manipulateAsync` to 500x500, compress 0.8, JPEG format. Return manipulated URI.

2. `takeProfilePhoto(): Promise<string | null>` — Request camera permissions. Launch `ImagePicker.launchCameraAsync` with `allowsEditing: true`, `aspect: [1, 1]`, `quality: 1`. Same manipulation and return pattern.

Both functions throw descriptive errors if permissions denied ("Camera roll permission is required to choose a profile photo" / "Camera permission is required to take a profile photo").
