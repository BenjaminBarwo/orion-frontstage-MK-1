**Create components/auth/password-strength-meter.tsx:**

- Accept `password: string` prop
- Use `useMemo` to calculate strength from password (performance per Research pitfall 7)
- Scoring: +1 for length >= 8, +1 for uppercase, +1 for lowercase, +1 for number, +1 for special char
  - Score 0-2 = "weak" (red `#FF4444`)
  - Score 3-4 = "medium" (gold `#C5A44E`)
  - Score 5 = "strong" (green `#4CAF50`)
- Render a horizontal bar with animated width (use `react-native-reanimated` `useAnimatedStyle` + `withTiming` for smooth width transition)
- Bar background: `#2A2A2A`, bar fill: colored based on strength
- Below bar: text label showing "Weak" / "Medium" / "Strong" in the corresponding color
- Return null if password is empty (no meter shown for empty field)
- Import colors from `@/constants/theme` authTheme

**Create components/auth/social-auth-buttons.tsx:**

- Accept `onGooglePress: () => void`, `onApplePress: () => void`, `isLoading: boolean` props
- Render two buttons stacked vertically with 12px gap:
  1. "Continue with Apple" button — dark surface color (`#1A1A1A`), white text, Apple logo icon (use SF Symbol via @expo/vector-icons Ionicons "logo-apple")
  2. "Continue with Google" button — dark surface color, white text, Google logo (use @expo/vector-icons AntDesign "google" or Ionicons "logo-google")
- Apple button renders only on iOS (use `Platform.OS === 'ios'` check)
- Both buttons: height 52px, border-radius 12, border 1px `#2A2A2A`
- Loading state: show ActivityIndicator, disable buttons
- Buttons disabled when isLoading is true

**Create components/auth/auth-input.tsx:**

- A styled TextInput wrapper for auth forms that matches dark premium theme
- Props: all standard TextInput props + `label?: string`, `error?: string`
- Style: background `#141414`, border 1px `#2A2A2A` (unfocused) / `#C5A44E` (focused via `onFocus`/`onBlur` state), border-radius 12, padding horizontal 16, padding vertical 14, white text, placeholder color `#9A9A9A`
- If `label` provided: render text above input in muted color
- If `error` provided: render error text below input in red (for field-level hints only — main errors go to toast per user decision)
- Handle `secureTextEntry` toggle: if prop is provided, show eye/eye-off icon button on the right to toggle visibility
- Use `forwardRef` for ref forwarding (enables focus chaining between inputs)
- Font size 16, line height 22

All components import from `@/constants/theme` for colors and spacing.

```
try {
  setIsSubmitting(true);
  await signUp(data.email, data.password);
  showAuthSuccess('Account created! Welcome to MVR.');
  router.replace('/welcome');
} catch (error) {
  showAuthError(error as Error);
} finally {
  setIsSubmitting(false);
}
```
