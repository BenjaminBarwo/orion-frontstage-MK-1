**Create app/(auth)/reset-password.tsx — Deep link reset handler:**

This screen handles the deep link callback after user clicks the password reset link in their email.

1. Heading: "Set New Password" in white (28px bold)
2. Subtitle: "Enter your new password below" in muted text
3. New password field: `AuthInput` with `secureTextEntry`, uses `newPasswordSchema` from Zod schemas
4. Confirm password field: `AuthInput` with `secureTextEntry`
5. Password strength meter below new password field
6. "Update Password" button — gold background

Use `useForm` with `zodResolver(newPasswordSchema)` which validates password strength + confirms passwords match.

**onSubmit:**
```
try {
  setIsSubmitting(true);
  const { error } = await supabase.auth.updateUser({ password: data.password });
  if (error) throw error;
  showAuthSuccess('Password updated successfully!');
  router.replace('/(auth)/sign-in');
} catch (error) {
  showAuthError(error as Error);
} finally {
  setIsSubmitting(false);
}
```

Dark premium styling matching other auth screens. KeyboardAvoidingView wrapping.
